# AtlasQuant — Política de Privacidade (RASCUNHO)

> **RASCUNHO INTERNO — REVISÃO JURÍDICA/PRIVACIDADE OBRIGATÓRIA ANTES DE PUBLICAÇÃO.**

Este documento é um mapa para a política final. Não afirma conformidade legal concluída.

## Inventário a validar
- Dados de conta necessários para autenticação e administração.
- Dados técnicos mínimos para segurança, auditoria e diagnóstico.
- Dados de cobrança somente quando houver integração de pagamento aprovada.
- Dados de provedores/conectores somente conforme configuração e consentimento aplicáveis.

## Princípios internos
Minimização de dados, controle de acesso por função, revogação de sessão quando a conta muda, proteção de credenciais e ausência de secrets em logs/commits/suporte.

## Terceiros
Todo provedor de autenticação, hospedagem, dados, voz, pagamento ou distribuição deverá ter finalidade, base aplicável, retenção e transferência avaliadas antes do lançamento.
