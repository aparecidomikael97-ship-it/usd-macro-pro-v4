# AtlasQuant — Checklist de Licenciamento Comercial de Dados

**PREPARAÇÃO INTERNA — NÃO SIGNIFICA LICENÇA COMERCIAL APROVADA.**

Para cada fonte/provedor usado em produção pública:
- Identificar razão social/produto e documentação oficial.
- Confirmar se uso comercial, exibição e redistribuição são permitidos.
- Confirmar limites, cache, armazenamento histórico e atribuição.
- Confirmar cobertura de instrumentos e direitos para usuários finais.
- Registrar plano/tier contratado e evidência de autorização.
- Mapear termos para API, RSS, scraping proibido/permitido e derivados.
- Registrar retenção e política de exclusão.
- Definir fallback quando licença, cota ou disponibilidade falhar.
- Aprovação humana obrigatória antes de marcar `data_licensing_ok=True`.

Fontes atualmente utilizadas ou planejadas devem ser auditadas individualmente; presença técnica no código não é evidência de direito comercial.
