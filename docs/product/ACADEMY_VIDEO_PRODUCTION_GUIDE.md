# AtlasQuant Academy — Guia de Produção dos Vídeos

## Regra de duração

- Nenhum vídeo deve ultrapassar **20 minutos**.
- Se o conceito couber bem em 4–10 minutos, não esticar.
- Um conceito complexo pode virar uma sequência de vídeos curtos em vez de um vídeo longo.

## Linguagem

- português simples;
- começar no que o aluno já conhece;
- uma ideia principal por bloco;
- explicar siglas na primeira aparição;
- evitar linguagem de certeza (“vai subir”, “vai dar gain”);
- usar “contexto”, “confirmação”, “invalidação” e “risco”.

## Visual

Prioridade para:
1. gráfico limpo;
2. poucos candles;
3. animação passo a passo;
4. região destacada;
5. só depois adicionar nomes/siglas;
6. mostrar pelo menos um exemplo inválido;
7. fechar com checklist visual.

Evitar:
- tela cheia de indicadores;
- narrador lendo texto estático;
- 15 linhas e zonas ao mesmo tempo;
- exemplo escolhido só porque “ficou bonito depois”.

## Estrutura padrão

1. **Gancho** — o problema que o conceito resolve.
2. **Construção** — desenhar o gráfico do zero.
3. **Como surge** — mostrar a sequência candle por candle.
4. **O que confirma**.
5. **O que invalida**.
6. **Erro comum**.
7. **Como o AtlasQuant mostra isso**.
8. **Resumo/checklist**.

## Conceitos prioritários

### Ponte para quem vem da análise técnica
Suporte/resistência → stops/liquidez → sweep → displacement → estrutura.

### FVG
Usar 3 velas e destacar com precisão a faixa sem sobreposição entre vela 1 e vela 3 ao redor do displacement.

### OTE / Fibonacci
Mostrar:
- swing válido;
- 50% como equilibrium;
- faixa OTE 62–79%;
- 70,5% como referência do modelo, não número mágico;
- confluência e invalidação.

### Order Block
Não ensinar “última vela contrária” como regra suficiente. Exigir origem relevante + displacement/consequência estrutural + invalidação.

### Breaker / Mitigation
Mostrar a sequência que faz uma zona mudar de função; evitar renomear qualquer suporte/resistência rompido.

### BOS / CHOCH / MSS
Diferenciar continuidade, mudança de comportamento e ruído de timeframe pequeno.

### Sessões
Asia High/Low, Londres, New York AM/PM, sweep e eventos macro. Horário sozinho não é sinal.

### Volume Profile
Exibir a fonte do volume. No Forex spot, nunca chamar tick/volume de um provedor de “volume centralizado de todo o mercado”.

### Guia do aplicativo
Ensinar:
- Iniciante x Avançado;
- Radar;
- Compra/Venda/Não Operar;
- “Por que está assim?”;
- voz;
- Safety Core/dados stale;
- Academy;
- Paper/validação.

## Entregáveis por aula

Cada tópico deve ter:
- roteiro curto;
- storyboard detalhado;
- duração estimada;
- instrução visual por cena;
- texto didático por cena;
- indicação de erro comum;
- arquivo final/URL somente quando renderizado;
- revisão humana antes de marcar como publicado.

Os storyboards JSON exportados pelo próprio AtlasQuant servem como contrato para futura renderização em ferramenta de vídeo.
