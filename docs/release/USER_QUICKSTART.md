# AtlasQuant — Guia Rápido do Usuário

Este guia é para o primeiro acesso. Ele descreve a leitura segura da plataforma e não transforma score em certeza nem habilita ordens reais.

## Primeiro acesso

1. Entre com sua conta.
2. Abra a **Central** e confirme o estado geral.
3. Confira **Data Confidence** e frescor dos dados.
4. Leia o **Safety Core** antes de qualquer interpretação operacional.
5. Confira contexto macro, força relativa e pares.
6. Use o **Market Map** e o scanner técnico somente quando os dados estiverem válidos.
7. Se houver hard block, dado stale ou mercado fechado, trate o estado como **não operar/aguardar**.
8. Para treinamento, use **Paper Trading**, Backtest e Academy.

## Ordem recomendada de leitura

**Estado → Qualidade dos dados → Contexto macro → Força relativa → Safety Core → Estrutura técnica → Plano → Invalidação.**

Não pule diretamente para BUY/SELL sem conferir bloqueios e qualidade.

## Macro Briefing

O Macro Briefing resume o contexto disponível. O texto pode ser usado mesmo quando a narração TTS externa não estiver configurada.

## Academy

A Academy contém trilha textual e roteiro/storyboard por aula. Vídeo final só deve ser considerado disponível quando houver mídia renderizada/publicada.

## Paper Trading

Paper Trading é simulação. Zero operações pode ser um resultado correto quando os gates não liberam entrada. Custos simulados não representam promessa de execução real.

## Instalação

- Android/Windows/macOS/Linux: use a opção de instalar/adicionar aplicativo do navegador compatível.
- iPhone/iPad: Safari → Compartilhar → Adicionar à Tela de Início.
- Google Play/App Store permanecem canais separados até publicação nativa verificada.

## Segurança

Nunca envie em suporte:
- senha;
- token;
- secret;
- chave de API;
- dados completos de cartão.

USER, SALES e ADMIN não habilitam trading real. Broker e ordens reais permanecem desativados no estado atual.
