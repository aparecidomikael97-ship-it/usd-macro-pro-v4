# AION B2B Pilot Activation Ceremony V1\n\nStatus: **staging / owner signature verification / no activation execution**.\n\n## Objective\n\nVerify an explicit HUMAN_OWNER activation decision only after a clean\n`READY_FOR_ACTIVATION_CEREMONY` preflight.\n\nAccepted choices are exactly:\n\n- `AUTHORIZE_PILOT_ACTIVATION`;\n- `DENY_PILOT_ACTIVATION`.\n\nFree text, booleans, `ok`, `approved`, `activate`, or `vamos lá` are not\nconverted into activation authorization.\n\n## Preconditions\n\nThe source preflight must remain:\n\n- schema `ATLASQUANT_AION_B2B_PILOT_ACTIVATION_PREFLIGHT_V1`;\n- state `READY_FOR_ACTIVATION_CEREMONY`;\n- no blockers;\n- activation_ceremony_eligible=true;\n- activation_request_issued=false;\n- owner activation signature required;\n- owner activation signature not already verified;\n- all activation/external-action flags false;\n- valid owner / tenant / workspace scope;\n- candidate, proposal and pilot IDs present;\n- environment and preflight digests valid.\n\n## Signed request\n\nThe external Ed25519 owner signature binds:\n\n- exact activation decision;\n- owner / tenant / workspace;\n- candidate ID;\n- proposal ID;\n- pilot ID;\n- environment digest;\n- preflight digest;\n- ceremony ID;\n- nonce;\n- issued/expires timestamps;\n- owner key ID/version/fingerprint;\n- activation/external-action flags frozen at false.\n\n## Freshness and anti-replay\n\nThe request window is at most 180 seconds.\n\nA durable nonce registry binds the nonce to owner/tenant/workspace/pilot,\npreflight digest, request digest and owner key version.\n\nReplay fails closed.\n\n## AUTHORIZE semantics\n\nA valid owner signature produces only:\n\n`ACTIVATION_AUTHORIZATION_VERIFIED_PENDING_PERSISTENCE`\n\nIt records verified intent in memory but still keeps:\n\n- activation_record_persisted=false;\n- pilot_activation_authorized=false;\n- pilot_activated=false;\n- customer_contact_authorized=false;\n- contract_signature_authorized=false;\n- billing_authorized=false;\n- spend_authorized=false;\n- provisioning_authorized=false;\n- deploy_authorized=false;\n- crm_write_authorized=false;\n- production_mutation_authorized=false.\n\nThe result requires a separate activation-record persistence layer.\n\n## DENY semantics\n\nA valid denial produces:\n\n`ACTIVATION_DENIAL_VERIFIED_PENDING_PERSISTENCE`\n\nand remains ineligible for activation execution.\n\n## Safety boundary\n\nThis module never captures a private key, persists authorization, activates a\npilot, contacts a customer, provisions resources, bills, deploys, writes CRM\ndata, calls providers or mutates production.\n
