## Possible custodians, not approved vendors

Earlier architecture documents already compare **Cloudflare Durable
Objects SQLite** and **AWS DynamoDB conditional writes** as D1 candidates,
and **AWS S3 Object Lock COMPLIANCE** as a D2 retention layer candidate.
A Cloudflare DO alone can be rolled back via PITR; S3 Object Lock retains
versions but does not by itself prove the latest logical head.

Separate AWS and Cloudflare accounts administered by a single operator
with the same recovery roots still may NOT provide independence against
coordinated compromise. Claims of separate physical paths or separate
Ed25519 keys are not equivalent to independently verifiable authority.

The existing 34-question RFI remains a draft; A152 sends nothing.
Do not create Cloudflare or AWS services, credentials, retention policies,
or expenses without a distinct explicit owner decision.
